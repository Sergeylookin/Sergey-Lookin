# tools/

Небольшие скрипты обслуживания сайта. Запуск — из корня проекта (`D:\Design\Portfolio`), нужен Node.

Сайт остаётся статикой: эти скрипты — удобство для разработки, а не требование для показа. Собранные `.html` открываются и хостятся как есть.

---

## `build-pages.mjs` — единый источник общего «каркаса»

Раньше шапка (`<nav>`), подвал (`<footer>`), блок ссылок в `<head>` и хвост `<script>` были скопированы в 14 файлов и разъезжались (версии `?v=`, отсутствие `aria-current` и т.п.). Теперь эти зоны и номер версии заданы в ОДНОМ месте — в шапке `build-pages.mjs` (`VERSION`, `SHARED_I18N`, `PAGES`) — и переписываются в страницы автоматически.

```bash
node tools/build-pages.mjs          # пересобрать каркас во всех страницах
node tools/build-pages.mjs --check  # только проверить (exit 1 при рассинхроне) — для CI/pre-commit
```

Что переписывается: блок favicon/шрифты/CSS в `<head>`, `<nav>`, `<footer>`, теги `<script>` внизу — на 13 однотипных страницах (about, portfolio, projects/01–10). `index.html` и `404.html` имеют особый каркас — им синхронизируется только `?v=`.

Что НЕ трогается (правится в страницах напрямую): `<title>`, `<meta>`/OG/Twitter, ссылка skip, весь `<main>`, словарь `<script id="i18n-data">`.

Обычный порядок работы: правишь контент/тексты прямо в `.html`; если поменял общий каркас или поднял `VERSION` — прогони `node tools/build-pages.mjs`.

`SHARED_I18N` — общие ключи словаря (nav.\*, ft.\*). Скрипт сверяет их значения во всех словарях и предупреждает о расхождении (не переписывает — только сигналит).

**Поднять версию ассетов** (после правки CSS/JS): поменяй `VERSION` в `build-pages.mjs` и запусти его — проставит новый `?v=` во всех 14 файлах.

## `minify.mjs` — минификация CSS/JS (esbuild)

Страницы ссылаются на `*.min.css` / `*.min.js`; исходные `core/site/manifest.css` и `site/manifest/smooth-scroll.js` остаются читаемыми. `npm run build` сначала минифицирует, потом синхронизирует каркас:

```bash
npm run build     # = minify + build-pages (обычный порядок)
npm run minify    # только минификация
```

CSS минифицируется полностью; JS — **без переименования идентификаторов** (только пробелы/комментарии/синтаксис), т.к. это глобальные скрипты, на чьи имена ссылаются инлайн-скрипты index.html. Если правишь исходник `.css`/`.js` — прогони `npm run build` (иначе `.min` устареет). Замер Lighthouse (index, локально без gzip): perf 75→81, LCP 4.4→3.8с после минификации; на проде с gzip — лучше.

## `build-images.mjs` + `inject-srcset.mjs` — адаптивные картинки

Мобильным больше не отдаются десктопные картинки: для каждого крупного изображения генерятся варианты 480/960/1440 px, а в `<img>` проставляются `srcset`/`sizes`. Нужен `sharp` (`npm install` поставит из devDependencies).

```bash
node tools/build-images.mjs --list   # показать размеры всех картинок
npm run images                        # сгенерировать варианты <name>-<w>.webp
npm run srcset                        # проставить srcset/sizes в <img> (идемпотентно)
```

Порядок: сначала `npm run images` (создаёт варианты рядом с оригиналом), затем `npm run srcset`. `sizes` подбирается по ширине источника: превью в сетке, полноширинные детальные (1920), «в ряд» (940) и портрет `about`. Варианты (`*-480/960/1440.webp`) — часть репозитория. `<video>`-постеры srcset не поддерживают, поэтому не трогаются.

## Видео-превью (разовая перекодировка, нужен ffmpeg)

Превью-ролики (`assets/vid/*.mp4`) пережаты H.264 CRF 30 без звука (mk 3.4→1.15 МБ, chobies 1.68→0.74, runa 1.09→0.36). Если добавляешь новый ролик — прогони его так же (нужен `ffmpeg`; поставить: `winget install Gyan.FFmpeg`, может требовать прав администратора):

```bash
ffmpeg -y -i in.mp4 -an -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 30 -preset slow -movflags +faststart out.mp4
```

## `set-domain.mjs` — абсолютные URL для превью в соцсетях

`og:image`/`twitter:image` должны быть АБСОЛЮТНЫМИ — Telegram, X, Facebook, LinkedIn не резолвят относительные пути, и превью не рендерится. Запусти, когда будет известен публичный адрес:

```bash
node tools/set-domain.mjs https://твой-домен.com
```

Проставит абсолютные `og:image`/`twitter:image` + `og:url` + `<link rel="canonical">` на всех 14 страницах. Идемпотентно — можно перезапускать при смене домена.
